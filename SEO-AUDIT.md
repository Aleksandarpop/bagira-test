# SEO Content Audit
## https://www.bagira.bg/
### Date: 2026-03-18

---

## SEO Health Score: 52/100

**Summary:** Bagira.bg is a Bulgarian technical hypermarket e-commerce site based in Stara Zagora with 1,300+ products across 12+ categories. While the site has solid fundamentals (HTTPS, fast TTFB, basic schema markup), there are significant SEO gaps including an empty H1, Cyrillic URLs, missing category descriptions, weak E-E-A-T signals, and no content marketing strategy.

### URL Structure
- **Status:** Fail (Critical)
- **Current pattern:** `bagira.bg/39687/мотофреза-7-кс-208cc-moller`
- **Issues:**
  - **Cyrillic characters in URLs** — Major issue for sharing, linking, and some crawlers. URLs become percent-encoded monstrosities when copied
  - Numeric product IDs in URL path add no SEO value
  - Category URLs are entirely Cyrillic: `/машини`
- **Recommended:** Use transliterated Latin URLs: `/mashini/motfreza-7ks-208cc-moller`

1. **Add text-based H1 to homepage** — Currently empty. Should read "Технически хипермаркет БАГИРА - Инструменти, Машини и Строителни Материали"

3. **Fix Cyrillic URLs** — Migrate to transliterated Latin URLs with 301 redirects. Current Cyrillic URLs cause sharing/linking issues
4. **Improve homepage meta description** — Expand to 150-160 chars with value proposition and CTA

### High Priority (This Month) — Expected Impact: +10-15% organic traffic

2. **Implement lazy loading on all below-fold images** — Only 4/46 images lazy-loaded
3. **Add responsive images (srcset)** — None currently implemented
4. **Add LocalBusiness schema** — Physical store in Stara Zagora should have LocalBusiness structured data
5. **Add FAQ schema** — Common product questions with structured data for rich results
6. **Fix all missing alt text** — 5 images on homepage alone missing alt text

5. **Implement breadcrumb schema on all pages** — Currently only on product pages

### Low Priority (When Resources Allow)
